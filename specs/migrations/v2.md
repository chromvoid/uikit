# UIKit 2.0 migration

UIKit 2.0 keeps reusable foundation and documented component custom-property contracts. ChromVoid product semantics now live in the consuming product theme.

| Removed UIKit family                                                                | ChromVoid product replacement |
| ----------------------------------------------------------------------------------- | ----------------------------- |
| `--cv-color-lockscreen-*`, `--cv-gradient-lockscreen-*`                             | `--welcome-lockscreen-*`      |
| `--cv-color-splash-*`, `--cv-gradient-splash-*`                                     | `--splash-*`                  |
| `--cv-color-media-mini-*`, `--cv-gradient-media-mini-*`, `--cv-shadow-media-mini-*` | `--media-mini-*`              |
| `--cv-gradient-audio-waveform-*`                                                    | `--media-audio-*`             |
| `--cv-gradient-card-*`                                                              | `--pm-payment-card-*`         |
| `--cv-gradient-scroll-edge-*`, `--cv-scroll-edge-*`                                 | `--app-scroll-edge-*`         |

Applications using ChromVoid product styling should import `@project/theme/webview.css`. Standalone UIKit consumers continue importing `@chromvoid/uikit/theme/tokens.css`.
